# 🚦 Integrated Traffic Management System Using AI

An AI-powered Intelligent Traffic Management System that detects vehicles in multiple lanes using Computer Vision and dynamically controls traffic signals based on real-time traffic density. The system integrates software with hardware traffic lights to reduce congestion, minimize waiting time, and improve traffic flow. It also incorporates Automatic Number Plate Recognition (ANPR) for law enforcement and a Crime Reporting App for faster emergency response.

---

## 📌 Short Description

This project aims to automate traditional traffic signal systems using Artificial Intelligence and Computer Vision.

The system:
- Detects vehicles in multiple traffic lanes in real time.
- Counts vehicles in each lane using object detection.
- Dynamically allocates green signal duration based on traffic density.
- Integrates with hardware traffic lights for automatic signal control.
- Detects vehicle number plates for law enforcement.
- Includes a Crime Reporting App to enable immediate reporting and response to incidents.

## 🚀 Key Highlights

- Developed an **Integrated Traffic Management System Using AI** using **Computer Vision** to detect and count vehicles across multiple traffic lanes in real time.

- Implemented **YOLO and OpenCV** for accurate vehicle detection and dynamically controlled traffic signals based on live traffic density.

- Integrated the AI software with **Raspberry Pi-based hardware traffic lights** for real-time automated signal switching.

- Implemented **Automatic Number Plate Recognition (ANPR)** to identify vehicles for traffic monitoring and law enforcement.

- Designed and integrated a **Crime Reporting Application** to enable citizens to report incidents instantly and facilitate faster emergency response.

- Achieved approximately **92% vehicle detection accuracy**, significantly reducing unnecessary waiting time and improving traffic flow.

---

## ⚙️ System Workflow

1. Capture live traffic video.
2. Detect vehicles using the AI model.
3. Count vehicles in each lane.
4. Compare traffic density across all lanes.
5. Allocate green signal duration dynamically.
6. Send control commands to Raspberry Pi.
7. Switch hardware traffic lights automatically.
8. Detect vehicle number plates for monitoring.
9. Allow users to report crimes through the mobile application.
